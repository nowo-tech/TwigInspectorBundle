# Twig Inspector Bundle – Demo (Symfony 8.0)

Demo app for **nowo-tech/twig-inspector-bundle** on Symfony 8.0.

## Quick start

From the bundle root or `demo/`:

```bash
make up-symfony8
make install-symfony8
# App: http://localhost:8003 (or port in .env)
```

From this directory:

```bash
cp .env.example .env   # if not done
make up
make install
```

See the [parent README](../README.md) for full documentation, Web Profiler, and Docker details.

## Makefile

Run `make help` for available targets (e.g. `up`, `down`, `install`, `shell`, `link-bundle`, `update-bundle`).
